FORBES — РЕЙТИНГ И КЛУБ. ГОТОВАЯ ПРЕЗЕНТАЦИОННАЯ СБОРКА

ЗАПУСК
Распакуйте ZIP. Откройте index.html в браузере.
Нажмите «Форбс» → «Попасть в Forbes».
Ссылка #club открывает клуб сразу, #forbes — рейтинг.
Дизайн рассчитан на игровой планшет 1280×800 и масштабируется под окно.

ЧТО ДОБАВЛЕНО
1. Вход в клуб по общему капиталу персонажа.
2. Порог сервера 78 — 350 000 000 игровых рублей включительно.
3. Формула: наличные + банк + бизнес + недвижимость + транспорт + прочее
   имущество − обязательства. В этом прототипе учитывается сумма по категории.
4. Анимация проверки всех семи категорий.
5. Допуск, недостаточный капитал, ручная проверка при неизвестном пороге.
6. Предлагаемые уровни относительно порога: MEMBER 1×, VIP 2×, ELITE 5×,
   LEGEND 10×. Для сервера 78: 350 млн / 700 млн / 1,75 млрд / 3,5 млрд.
7. Форма заявки: ник, сервер, заявленный капитал, VK, причина, подтверждение.
8. Сохранение демо-заявки в этом браузере и копирование текста для передачи.
9. Ссылки VK и техподдержки появляются только после настройки контактов.
10. Рейтинг из 29 игроков, их суммы, имена и VK из исходной сборки сохранены.
    В профиле отображается расчётный уровень по известной сумме.

КАК ПОКАЗАТЬ РАЗРАБОТЧИКАМ
Вкладка «Мой капитал» → «Настроить демо».
Выберите «Ниже порога», «Ровно 350 млн», MEMBER, VIP, ELITE или LEGEND.
Нажмите «Применить суммы» → «Проверить мой капитал».
Можно вручную задать любые активы и обязательства в миллионах рублей.
Переключите на «Другой сервер»: без заданного порога допуска не будет.
В «Заявке» заполните данные и сохраните черновик. Он останется после
перезагрузки в том же браузере, если локальное хранение разрешено.
В «Как это работает» — правила оценки и уровни клуба.

СОСТОЯНИЕ ИНТЕГРАЦИИ
По умолчанию mode: 'demo'. Все суммы профиля и допуск демонстрационные.
Сохранение заявки в демо НЕ отправляет её администрации.
В демо черновики хранятся раздельно по серверу на данном устройстве.
Если браузер запрещает хранение, текст остаётся доступным до закрытия страницы.
Рейтинг TOP-29 — статический снимок, он не синхронизируется с игрой.
Реальное подтверждение владения, оценки, приём заявок и обновление рейтинга
требуют серверной интеграции. Готов клиент и описан контракт API.

НАСТРОЙКИ
club-config.js — режим, адрес API, пороги серверов, уровни, контакты.
Добавление сервера, пример синтаксиса (сумму определяет администрация):
servers: { 78: { name: 'Vladimir', minimum: 350000000 }, ... }
Никаких выдуманных порогов для других серверов в сборке нет.
contacts.vk — HTTPS-ссылка на официальный канал приёма заявок VK.
contacts.support — HTTPS-ссылка на официальную техподдержку.
Не указывайте личный VK игрока вместо приёмной администрации.
Переход по ссылке не отправляет текст автоматически: игрок вставляет его сам.

ФАЙЛЫ
index.html, tablet.js, tablet.css, leaderboard.css — планшет и рейтинг.
club-config.js — настройки.
club-core.js — расчёты и валидация.
club.js, club.css — интерфейс клуба, заявки и API-клиент.
INTEGRATION-FORBES.txt — подробный контракт для разработчиков игры.
tests/club-core.test.cjs — проверки расчётов и валидации.
site.html и остальные исходные страницы сохранены.

GITHUB PAGES
Загрузите распакованное содержимое ZIP в корень репозитория с заменой файлов.
Не создавайте дополнительную вложенную папку: index.html лежит в корне.
Демо не требует сборки, npm, Firebase или ключей.
Исходные разделы сайта могут иметь собственные зависимости и настройки.
GitHub Pages обслуживает статические файлы. Реальный API нужно подключать
на подходящем сервере с общим origin либо через его reverse proxy.
