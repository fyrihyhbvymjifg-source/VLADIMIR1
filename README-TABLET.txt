FORBES — игровой планшет / рейтинг игроков

ОТКРЫТИЕ
1. Откройте index.html в браузере (или опубликуйте содержимое ZIP на GitHub Pages).
2. На игровом планшете нажмите на кнопку «Форбс», подсвеченную анимированной стрелкой.
3. Внутри планшета откроется рейтинг из 29 игроков. Список прокручивается внутри панели.
4. Нажатие на строку игрока открывает карточку с ником, именем, состоянием и VK.
5. Стрелка «Назад» возвращает в главное меню. Клавиша Esc закрывает карточку или возвращает в меню.

СОСТАВ
index.html — новая главная страница планшета
leaderboard.css — оформление игрового рейтинга
tablet.css — оформление планшета
tablet.js — интерфейс и рейтинг
assets/data/data.js — имена и VK из исходного проекта
site.html и остальные HTML — сохраненные страницы исходного сайта

СПИСОК
29 игроков и суммы из предоставленного задания, от Lauren_Degraf до Vito_Luchiano.
В рейтинге отсутствуют поисковая строка, фильтры, сравнение и лишние блоки.
Данные рейтинга для этого прототипа статические; изменения на исходном сайте не синхронизируются автоматически.

GITHUB PAGES
Распакуйте архив в корень репозитория, сохранив папку assets и остальные файлы.
Settings -> Pages -> Deploy from a branch -> main -> /(root).

ТЕХНОЛОГИИ
Чистые HTML, CSS, JavaScript. Без фреймворков. Базовый дизайн 1280x800,
масштабирование под экран планшета. Внешние ссылки VK откроются в новой вкладке.
