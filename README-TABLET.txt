FORBES — ПЛАНШЕТНАЯ ВЕБ-ВЕРСИЯ

Откройте index.html в браузере. Это новый игровой планшетный интерфейс.
Нажмите «Форбс» (третья строка, четвертая иконка), чтобы открыть раздел.
Нажмите любую из шести карточек, чтобы посмотреть описание и перейти на соответствующую страницу исходного сайта.
«Назад» возвращает в игровое меню. Esc закрывает окно / возвращает назад.

Оригинальная главная страница сохранена как site.html. Все исходные файлы сайта, разделы и assets сохранены.
Новый интерфейс сделан на чистом HTML, CSS и JavaScript без внешних зависимостей.

GITHUB PAGES:
1. Распакуйте ZIP.
2. Загрузите содержимое архива (index.html, tablet.css, tablet.js, assets и остальные файлы) в корень репозитория.
3. Settings > Pages > Deploy from a branch > main / (root).
4. Откройте опубликованный адрес.

Планшетный экран проектировался для пропорций 1280x800 и автоматически масштабируется под окно браузера.
Пункты игрового клиента, которые не реализованы в исходном сайте, отображают понятное информационное окно, а не имитируют работу сервера.
